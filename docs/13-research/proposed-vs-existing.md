# Proposed vs Existing

## Comparison Table

| Parameter | Traditional/High-End Systems | Proposed Prototype |
|---|---|---|
| **Cost** | High (thousands to tens of thousands USD per station) | Target: Low (student/hackathon budget) |
| **Sensor quality** | Research-grade, sub-mPa noise floor | Prototype-grade, noise floor `To be validated` |
| **Wind-noise reduction** | Large pipe arrays (18–70 m) | Small manifold (1–5 m) |
| **Frequency range** | 0.02–4 Hz (IMS standard); some wider | 0.01–20 Hz (target) |
| **Deployment** | Specialized, fixed installations | Portable, flexible |
| **AI analysis** | Specialized algorithms (PMCC) | Integrated Isolation Forest anomaly detection |
| **Real-time dashboard** | Internal systems, not publicly accessible | Web-based, accessible via browser |
| **Event classification** | Automated (with extensive training data) | Anomaly detection only (MVP); classification `Future Scope` |
| **Data access** | Restricted or delayed | Immediate local access |
| **Customization** | Limited (proprietary/institutional) | High (open design) |
| **Educational value** | Limited | Strong — covers physics, electronics, DSP, AI |
| **Multi-sensor capability** | Yes (array per station) | Single sensor (MVP); arrays `Future Scope` |
| **Source localization** | Yes (via array processing) | Not available (single sensor) |
| **Reproducibility** | Requires specialized expertise | Designed for student reproduction |
| **Regulatory certification** | IMS-certified | Not certified |
| **Long-term reliability** | Proven (decades of operation) | `To be validated` |

## Where the Prototype Adds Value

1. **Accessibility:** Makes infrasound monitoring available to educational and research groups without large budgets
2. **Integrated AI:** Demonstrates AI anomaly detection as part of the sensing system
3. **Educational platform:** Covers a wide range of engineering disciplines in a single project
4. **Rapid prototyping:** Modular design allows quick iteration and experimentation
5. **Dashboard visualization:** Provides immediate, visual feedback on the infrasound environment

## Where Professional Systems Are Superior

1. **Sensitivity:** Orders of magnitude better noise floor
2. **Wind-noise reduction:** Much larger and more effective arrays
3. **Source localization:** Multi-sensor array processing
4. **Event classification:** Proven algorithms with decades of reference data
5. **Reliability:** Designed for years of continuous, unattended operation
6. **Global coverage:** Worldwide network provides comprehensive monitoring
