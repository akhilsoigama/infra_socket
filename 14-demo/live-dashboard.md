# Live Dashboard

## What the Live Dashboard Should Show During Demo

See [Dashboard](../06-software/dashboard.md) for the full dashboard specification.

### Essential Elements for Demo

1. **Sensor Status Indicator:** ONLINE (green)
2. **Live Pressure Waveform:** Updating in real-time (1–2 Hz refresh)
3. **Frequency Spectrum:** Current FFT output (updating per window)
4. **Normalized Anomaly Index Bar:** Visual indicator with threshold line
5. **Status Badge:** NORMAL (green) or ANOMALY (red)
6. **Alert Banner:** Appears when anomaly is detected

### Demo-Specific Dashboard Tips

- Maximize the browser window for visibility
- Use a dark theme if available (better projection visibility)
- Ensure the waveform and score are large enough to read from a distance
- Have the dashboard already running before the demo begins
