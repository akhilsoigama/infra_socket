# Phase Plan

## Phase 1: MVP (Current)

### Objective
Build and demonstrate a working end-to-end prototype: sensor → processing → AI → dashboard.

### Deliverables
- [ ] Assembled hardware prototype
- [ ] Signal processing pipeline (filter, FFT, feature extraction)
- [ ] Trained Isolation Forest model
- [ ] Web dashboard with live visualization
- [ ] Calibration test results
- [ ] Complete documentation

### Success Criteria
- System runs continuously for 24+ hours
- Detects controlled test signals as anomalies
- Dashboard displays live data and alerts
- Documentation is complete and consistent

---

## Phase 2: Improved Performance (`Future Scope`)

### Objective
Improve sensitivity, reduce false positives, validate over extended periods.

### Key Activities
- Expand wind-noise manifold
- Implement ensemble AI models
- Deploy outdoors for extended testing
- Implement temperature compensation

---

## Phase 3: Advanced Capabilities (`Future Scope`)

### Objective
Multi-sensor arrays, event classification, deep learning.

### Key Activities
- Deploy 3+ synchronized sensors
- Collect and label training data for event classification
- Train supervised classification models
- Implement array processing for source direction

---

## Phase 4: Network Deployment (`Future Scope`)

### Objective
Scale from single station to a network of stations.

### Key Activities
- Design and deploy central data server
- Build multi-station dashboard
- Enable community contributions
- Open data sharing
